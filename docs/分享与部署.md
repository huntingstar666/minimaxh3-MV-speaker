# 打包分享与部署

这个项目按「零构建 + 本机 ComfyUI」设计，分享给别人时可以只发代码仓库和 MV 包；
运行期数据（`data/`）和模型不在仓库里。

## 1. 分享什么

| 内容 | 说明 |
| --- | --- |
| `h3-workbench/` 代码 | 后端 + 零构建前端 + 示例数据目录结构（`data/` 被 gitignore，但 `data/creative-catalog.json` 被跟踪） |
| `skills/mv-pack-builder/` | 配套 Agent 技能：环境自检、包格式、提示词规则、包校验、导入/扩写/出片脚本 |
| `.h3pack.zip` MV / 数字人包 | 音频 + 参考图 + 参数 + 分段提示词，别人拖进工作台即可复现创作 |
| 文档 | `README.md`、`docs/MV包格式.md`、`docs/数据链路与已知限制.md` |

**不要分享**：`data/settings.json`（含 LLM key）、`data/projects/`（用户素材/成片）、
`vendor/` 之外的模型文件。

## 2. 接收方需要准备

1. Windows / Python 3.10+（有 `.venv` 更省事），或按 `requirements.txt` 安装依赖；
2. ffmpeg / ffprobe 在 PATH；
3. ComfyUI（0.43+，0.44.0 环境体检实测）及 [首次安装与环境体检](首次安装与环境体检.md) 列出的节点、模型；启动后自动体检，缺项会列清单；
4. 可选：本地 LLM（Ollama / 任意 OpenAI 兼容接口）用于 AI 扩写提示词；
5. 可选：`faster-whisper`（语音识别辅助切分）。

## 3. 部署步骤

```powershell
# 1) 解压/克隆代码，进入目录
cd h3-workbench

# 2) 安装依赖（推荐虚拟环境）
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt

# 3) 启动 ComfyUI 后运行工作台
.\start.bat
# 打开 http://127.0.0.1:8787
```

首次启动会生成 `data/settings.json`；在设置面板里确认 ComfyUI 地址、ffmpeg 路径、
LLM 配置和模型名。「设置 → 环境体检」会检查依赖、ComfyUI、节点与模型，缺节点可一键 `git 安装`，
缺模型按清单放置（不自动下载）。`/api/health` 显示 ComfyUI / ffmpeg / ASR / LLM 状态。

## 4. 导入 MV / 数字人包

- 打开工作台 → 左栏「导入 MV 包」→ 拖入 `.h3pack.zip`；
- 会自动创建项目、导入音频/参考图/分段/提示词/参数，并按包里的 `mode` 走
  `singing`（MV）或 `speaking`（数字人口播）；
- 没有时间轴的包会自动分析分段；导入后可以直接「开始生成」；
- 包格式与错误提示见 [MV包格式.md](MV包格式.md)。

## 5. 导出自己的 MV 包

顶部「导出 MV 包」→ 下载 `<项目名>.h3pack.zip`。包含音频、参考图、分段简报、
提示词、风格/滤镜/运镜与生成参数；不含已生成视频/成片，方便别人从头复现或继续改。

## 6. 安装配套技能（给 Agent 用）

```powershell
Copy-Item -Recurse -Force .\skills\mv-pack-builder "$env:USERPROFILE\.agents\skills\mv-pack-builder"
```

重启 Agent 会话后生效，之后可以直接说「用 mv-pack-builder 帮我做一支 MV」。
技能会先跑环境自检，再与用户确认参考图角色、歌词、风格/参数、是否出片，最后产出
可导入的包；工作台可用时还能直接导入、扩写提示词并出片。
