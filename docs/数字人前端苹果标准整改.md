# 数字人前端 · 苹果标准整改清单（2026-11-11）

> 目标：按 Apple HIG 的「清晰、直接、克制、可预期」重审数字人工作台，不再用窄栏塞表单、不再用原生下拉堆参数、不再把重要素材藏进分页。
> 规则：本文每条都有验收标准；实现一项、复查一项、达标后再提交。

## 0. 业务流程（先弄懂再改）

| 模式 | 素材 | 时间轴 | 分段方式 | 生成 |
| --- | --- | --- | --- | --- |
| 1 音频驱动 | **驱动音频（核心）** + 参考图 | 真实波形 + 切点 | 按音频能量 / ASR 切分，可拖切点 | 原声对口型，段间可硬切 / 首尾帧锚定 / 接缝接续 / 混合 |
| 2 参考音色 | **参考音色（核心）** + 参考图 + 台词 | 无音频波形，按台词估算时长 | 按标点与语速切分 | 每段用参考音色生成语音 |
| 3 无音频参考 | **音色描述（核心）** + 参考图 + 台词 | 同上 | 同上 | 用文字描述的音色生成语音 |

素材是项目级 `refs / audio / voices`；分段只有在 `ref_ids` 非空时才覆盖全局参考图。驱动音频与音色是「主素材」，不是高级设置。

## 2. 整改措施（逐条验收）

### P0-1 右栏改成真正的分组卡片（含黑金主题）
- 把「段间模式」「输出与生成」做成两张完整卡片：卡片头 + 分段控件 + 带图标/摘要/chevron 的设置行。
- 在 `avatar.css` 补黑金主题的 `.av-setting-row` 样式，不再只依赖 `avatar-light.css`。
- 设置行最小高度 44px，hover/active/focus 三态齐全。
- **验收**：黑金与 8-bit 两套主题截图；无系统默认灰按钮；键盘 Tab 能看到焦点环；点击行能打开对应卡片弹窗。

### P0-2 作品设定回到固定尺寸的卡片弹窗
- 左栏只保留「当前作品」摘要卡（作品名 / 模式 / 段数 / 设计状态）与「作品设定」主按钮。
- `#settings-tabs` + `#settings-body` 迁入 `#modal-settings`；弹窗外框固定 `min(920px,94vw) × min(86vh,760px)`，分页内容内部滚动。
- 设计分页改为两栏：左侧预览 + 右侧控制；不再在 300px 栏里挤压。
- **验收**：四个分页来回切换时外框尺寸不变；Esc / 遮罩 / 关闭按钮都能关；设计预览在 1440 与 1280 下不变形。

### P0-3 主素材显性化：驱动音频 / 参考音色 / 参考图
- 左栏「素材」区按模式显示：
  - 模式 1：驱动音频卡（文件名、时长、试听/停止、替换、重新分析）。
  - 模式 2：参考音色卡列表（名称、时长、试听）。
  - 模式 3：音色描述摘要卡。
  - 所有模式：参考图网格 + 拖拽上传 + 计数。
- 音频/音色卡直接调用现有上传与试听逻辑，不复制业务代码。
- **验收**：模式 1 打开项目不用进设置就能试听/替换音频；模式 2 不用进设置就能试听音色；参考图仍可拖拽；素材区显示 `N 图 · N 音色 · N 段`。

### P0-4 少量互斥选项不再用原生下拉
- 画幅：卡片网格（9:16 / 16:9 / 1:1 / 4:3 / 3:4 / 21:9，按后端列表渲染）。
- 清晰度：分段控件（草稿 / 标准 / 高清）。
- 接缝重叠：分段控件（5 / 22 / 39 帧）。
- 设计平台、音频模式：分段控件。
- 长列表（采样器 / 模型 / VAE / LoRA）只留在「高级生成参数」弹窗内，首屏不暴露；按 HIG，菜单式选择用于长列表，后续可替换为可搜索列表。
- **验收**：上述控件点击后底层值同步（读取 `readGeneration/readDesign` 结果一致）；刷新后回显正确；首屏不再出现原生 `<select>` 弹层。

### P1-1 版式与字体（8pt 网格）
- 功能性正文 ≥11px；辅助说明 ≥10px；仅装饰性角标允许 9px。
- 圆角统一 10 / 14 / 20；卡片内边距 14/16；行高 1.5–1.6。
- **验收**：截图对照；无 9px 以下功能性正文；主要点击目标 ≥32px 视觉、桌面行高 ≥44px（触控端按 44pt 处理）。

### P1-2 反馈与安全
- 上传中 / 分析中 / 生成中按钮有 busy 态与禁用原因。
- 删除参考图、删除音色统一二次确认；危险按钮不与主按钮相邻。
- 空态给一个明确主按钮（上传音频 / 写台词 / 上传参考图）。
- **验收**：逐步操作录屏或截图；每个失败路径有 toast；无“点了没反应”。

### P1-3 可访问性与键盘
- 所有交互可 Tab 到达；`:focus-visible` 有 2px 高对比焦点环。
- 弹窗 Esc 关闭、打开后焦点进入弹窗、关闭后回到触发按钮。
- 图标按钮有 `aria-label`；状态变化有文本，不只靠颜色。
- **验收**：只使用键盘完成“打开设定 → 切页 → 修改 → 关闭”；无控制台错误。
