### 1.3 模式 1 的段

- `edit_frames` 来自音频边界（24fps 刻度）；`generation_frames = segmenter.frames_for(edit_frames, 24)`；
- `frames = edit_frames`（成片/归一化长度）；`seconds = edit_frames/24`；
- `text`：有 ASR 时取该段 ASR 文本；否则按 script 行字数比例分配；都没有则空（A 腔可无台词）。

## 2. API（前缀 `/avatar/api`，JSON `ok:true`；旧接口只增不改）

### 2.1 系统

- `GET /health`（不变）
- `GET /options`（不变）
- `GET/PATCH /prompts`（不变；三腔系统提示词）
- `GET /effect-catalog` → `{"ok":true, **effect_catalog.catalog()}`
- `GET /design-defaults` → `{"ok":true,"design": design.default_design()}`

### 2.2 项目

- `POST /projects`：multipart `name,mode,script,voice_description,chars_per_second,target_seconds,max_seconds,generation`，`mode` 允许 1/2/3；可选 `voice`
  段长上限 5–30s（推荐 ≤15s；生成帧数吸附 `5+17k`，最大 719 帧 ≈29.96s）。
- `GET /projects`、`GET/PATCH/DELETE /projects/{id}`（PATCH 支持 `design` 深合并）
- `GET/PATCH /projects/{id}/design` → `{ok, design}`
- `POST /projects/{id}/design/suggest` body `{mode?: "effects|voice|beats", segment_index?: int}`
  → `{ok, suggestion:{style_system?, voice_card?, beats?}, warnings:[]}`（LLM 建议，失败给空）
- refs / voice / segments / prompts / generate / cancel / run / takes / assemble / media / download
  （现有接口保持不变；`/segments/{i}/prompt` 返回增加 `prompt_meta`）
- `POST /projects/{id}/anchor-frames/{slot}`：`slot ∈ first|last|mid`，multipart `image`（可选 `crop` JSON）
  → `{ok, project}`。落 `projects/<id>/anchor/<slot>.<ext>`（同槽位旧图先删），写 `anchor_frames[slot]`；
  校验大小 / 后缀 / 文件头魔数，非法 slot 返回 400。
- `PATCH /projects/{id}/anchor-frames/{slot}`：body `{crop}` 只改裁切、不重传图片；槽位为空时可带
  `{source:"refs/ref_01.png", crop}`，把默认继承的参考图提升成可裁切的自定义图（source 必须是项目内已存在文件）。
- `DELETE /projects/{id}/anchor-frames/{slot}`：删图并移除字段，该槽位回退到「该段第一张参考图」。
- 生成时：`first` 为空→用该段第一张参考图；`last`/`mid` 为空→跟随 `first`；
  带 `crop` 的槽位先用 ffmpeg 裁到 `anchor/.cache/crop-{hash}.png`（按当前 `aspect_ratio` 校正成精确画幅比例），
  再上传 ComfyUI。**同一张源图被多个槽位共用时只裁一次**：按 `filename` 归并，取 first → last → mid 的第一个非空
  `crop` 共用；前端保存裁切时也会把同一个 `crop` 同步 PATCH 到所有共用该图的槽位（未自定义的带 `source` 提升为自定义）。
  `workflow.build_anchor()` 对不同的图各建 `LoadImage`（按预处理再 `ImageScale`），
  中间锚点 `AddGuide.image` 用 `mid`；同图时复用节点，节点结构与旧版一致。
- `generation.anchor_resize`（bool）：true = 把裁切后的参考图等比缩放到视频分辨率（`ImageScale`）；
  false = 原图直进（不建 `ImageScale`）。缺省时沿用旧字段 `anchor_preprocess`（center_crop / stretch / none）。
  缩放算法用 `generation.anchor_upscale`（lanczos / bicubic / bilinear / area / nearest-exact）。
- `POST /projects/{id}/voice`（mode2）：上传任意长度录音（≤10 分钟），保留 `voice/source.wav`，
  自动截 12s 到 `voice/ref.wav`（2–15s 可调）；`DELETE` 同时清掉两者。
- `POST /projects/{id}/voice/sample` body `{start_seconds?, length_seconds?}`：从 `source.wav`
  重新截取音色样本（起点自动夹到 `0..源时长-样本长度`），返回 `{ok, project, voice}`；
  试听走 `GET /projects/{id}/media/voice/ref.wav`，原始录音 `GET .../media/voice/source.wav`。

### 2.3 模式 1 音频

- `POST /projects/{id}/audio` multipart `audio`（解码成 `source.wav`，mode1）→ `{ok, project}`
- `DELETE /projects/{id}/audio` → `{ok, project}`
- `POST /projects/{id}/analyze` body `{use_asr?:bool, asr_model?:str, asr_language?:str, script?:str, target_seconds?:float, max_seconds?:float}`

## 3. 提示词生成流程（后端）

> **首尾帧锚定（`stitch=anchor`）不走本节的 LLM 流程**：后端用固定模板
> `plan.ANCHOR_DEFAULT_PROMPT` 写入每段 `segments[].prompt`（`prompt_source=template`），
> 音频分析 / 切点 / 拆分合并 / 改项目参数时自动刷新；用户手改后 `prompt_source=manual`，
> 生成时优先使用用户版本。提示词里禁止出现 `black` 等否定色词（单采会黑背景）。

1. 组装 task 消息：三腔系统提示词（A/B/C）+ 中文任务书，任务书结构：
   - 音频腔与规则；文案；时长/帧数/画幅；镜头；参考图清单；参考音频；音色卡；
   - **设计层 JSON**（密度/安全区/风格系统/图形预算/graphics_mode/brand）；
   - **节拍表 JSON**（beats；可为空 → 让模型自己按技能规则设计并返回节拍建议）；
   - 输出要求：只输出提示词正文；若 beats 为空，允许在正文前输出 `BEATS:` JSON 行（见 §5）——后端解析后回填 beats，不写入正文。
2. LLM 参数：`max_tokens = max(现有, 16384)`；`temperature` 沿用；超时 ≥ 600s；Ollama 时 body 附 `options.num_ctx=32768`（通过 llm 客户端扩展，见 §8）。
3. 校验：`lint.lint_prompt(...)`（§5）。
4. 自动修复 1 轮：把 lint errors（+关键 warnings）拼成 follow-up user 消息，要求重出完整提示词；再 lint。
5. 失败回退：`compose_prompt()` 内置模板（A/B/C 语义已覆盖），meta.lint 记录。
6. 保存：`row.prompt`、`row.prompt_source`、`row.prompt_meta`（摘要行、lint、字数、效果数等）。
7. `graphics_mode=overlay` 时：任务书要求"不要在画面里生成任何文字/图标/卡片（由后期叠加）"，lint 不做特效配对检查；提示词只写人物表演/构图/光。

摘要行解析：若 LLM 输出以 `路线=Ref2VA` 开头的一行，提取为 `summary_line` 并从正文移除；否则由后端生成
`路线=Ref2VA ｜ 腔={A/B/C} ｜ 人数=1 ｜ 效果概念={primary_effect 列表} ｜ 密度={density} ｜ 目标语速≈5字/秒 ｜ 台词 {speech_chars} 字`。

## 5. lint.py（后端）

```python
def lint_prompt(text: str, *, mode: str = "Ref2VA", audio_mode: str | None = None,
                duration_seconds: float | None = None, target_cps: float = 5.0,
                graphics_mode: str = "generated") -> dict:
    """返回:
    {"ok": bool, "mode": str, "audio_mode": str|None, "chars": int, "speech_chars": int,
     "errors": [{"code": str, "message": str}], "warnings": [{"code": str, "message": str}]}
    """
```
检查项（对齐技能脚本，中文/英文术语兼容）：
1. 六段字段顺序（Ref2VA）或 Base 字段顺序；混 schema 报错；
2. `[Shot 1]` 必须存在；
3. A 腔（runtime）：禁止 `<Audio N>`/`audio reuse`/`audio reference`/音频保留标记/“参考音频N”；缺“驱动语音同步”告警；
4. B 腔（reference）：`<Audio 1>`、`summary` 含 `audio reference`、`retention_analysis` 含 `<Audio 1>: reference`；
5. C 腔（generated）：禁止 `<Audio N>`/`平台运行时驱动音频`；voice card 十维关键词检查（呈现/年龄/音高/共鸣质感/节奏/话筒/房间/anti-style）；
6. 台词块：`<d>[语言] ...</d>`；有台词时须出现"字/秒"或"chars per second"，并按 `duration_seconds × target_cps ± max(5,10%)` 检查预算；
7. 引号文案需有稳定性条款（字形/断行/拼写/不乱码/stable）；
8. 特效：有特效时须有触发、可读停留、退场/恢复、安全区/遮挡；按块检查入场/退场配对与 accumulation risk（graphics_mode=generated 时才查）；
9. 人物：视线、口型/音素、呼吸、恢复、眨眼、手势；
10. 闪烁安全；11. 长度 > 7000 告警；12. graphics_mode=overlay 时跳过特效检查，并允许提示词不含图形。
另提供 `extract_summary_line(text) -> tuple[str|None, str]`（返回摘要行与去掉摘要行的正文）。

## 7. overlay.py（确定性文字/logo 兜底）

- 不依赖 Pillow；用 **ffmpeg drawtext + overlay**（中文字体 `C:/Windows/Fonts/msyh.ttc`，缺失时回落 `simhei.ttf`）。
- `design.graphics_mode == "overlay"` 时生效；提示词不生成图形，由本模块按 beats 叠加：
  - 时间：`trigger` 在 `segment.text` 中的字符位置 ÷ cps → 起点；持续到下一 beat 起点或 `起点+2.5s`，且不超出本段；
  - 位置：`anchor` 映射（right_side→右侧安全区、lower_third→下三分之一、top_left、beside_speaker、world_space/surface→同 right_side 但更靠下）；
  - 样式：`style_system.accent_color`、`typography`（字重/字号档）、`material`（底框颜色/圆角用 box=1:boxcolor=...）；
  - logo：`design.brand.logo_refs` 里的参考图若存在，叠在右上角安全区，透明度 0.9（可选）。
- 接口：
```python
def compose_segment(project: dict, row: dict, source_video: Path, out_video: Path,

    """给单段视频叠加确定性文字/logo；无 beats/不可用时返回 False（调用方保留原视频）。"""
def compose_project(project: dict, project_dir: Path, out_final: Path) -> bool:
    """可选：对成片做整段叠加（先不做也行，优先单段）。"""
```
- job 在生成 take 落盘前调用 `compose_segment`；失败则用原视频并在 run.log 记 warning。
- 测试：`tests/avatar_overlay_test.py`：用 ffmpeg 造 3s 视频 + 1 个 beat，断言输出存在、且 `ffprobe` 时长不变（有 ffmpeg 才跑，否则 SKIP）。

## 8. 前端规格（web/avatar/**）

### 8.1 模式 1

- 模式 1 在「作品设定 · 音频页」上传驱动音频，左栏素材库直接显示可试听/替换的音频卡：
  - 音频 dropzone（accept audio/video；显示文件名/时长；可删除替换）；未上传时"分析"按钮禁用。
  - 参数：目标段长（默认 8s）、最长段长（默认 12s）、「语音识别辅助切分」开关（模型 small/base、语言 zh/auto）。
  - 「分析音频并分段」按钮 → `POST /audio`（若已上传则跳过）+ `POST /analyze`。
  - 音频波形时间线（峰值来自 `project.analysis.waveform.original`）：
    - 播放头（可点/拖），切点竖线可拖（调用 `PUT /cuts`，前端传秒）；播放头命中带与切点命中带分离，标尺区域只响应播放头；
    - 「在播放头切分」`POST /segments/{i}/split`；段卡「合并下段」`POST /segments/{i}/merge`；
    - 切点/分合段成功后刷新项目；提示最少 3 秒规则（沿用 MV 的错误提示）。
  - 段卡显示 `00:06.0 – 00:12.0 · 6.0s`，台词可编辑（默认 ASR/比例分配），提示词/生成/选片/重生成同模式 2/3。
- 模式 2/3 使用同一套作品设定弹窗与素材库。

### 8.2 设计面板（作品设定 · 设计页）

- 作品设定是固定尺寸卡片弹窗，四页签（基础 / 音频 / 参考图 / 设计）；设计页左列固定预览、右列控制。
- 基础：效果密度（低/中/高）、主辅色、字体语言（预设 chips + 自定义）、卡片材质（预设）、效果清单（多选，来自 `effect-catalog.effect_families`）、图形模式（生成式/后期叠加）。
- 高级设计折叠：平台安全区、图形预算、品牌色/Logo 参考、visual_style、motion_grammar/icon_family、完整四轴字段；`route` 固定 `Ref2VA`、`audio_mode` 由模式派生，只读展示。
- 「AI 建议」按钮：`POST /design/suggest`（effects / voice / beats），结果填入表单但需用户点保存。
- C 腔（模式 3）显示 10 维 voice card 表单 + 「AI 生成音色卡」按钮（`design/suggest mode=voice`）。
- `PATCH /projects/{id}/design` 保存。

### 8.3 节拍表（每段）

- 段卡内折叠「节拍表」：列表（触发词/职能/主效/锚点/可见文案/入场/退场/恢复/注意目标/手势/风险）+ 新增/删除行；
- 「AI 建议节拍」→ `POST /design/suggest {mode:"beats", segment_index}` 填充；
- 保存：`POST /segments/{i}/beats`（整段替换）。
- 无节拍时显示"生成提示词时 AI 会自动设计节拍"（后端允许 beats 为空）。

### 8.4 提示词 / lint UI

- 生成提示词后显示：来源徽标、`prompt_meta.summary_line`、字数/语速、效果数、lint 结果
  （errors 红 / warnings 黄，可展开）、「按 lint 修复」按钮（`prompt/repair`）。
- 提示词正文可编辑保存（现有 PATCH segment `prompt` 行为保留）。

### 8.5 叠加模式

- 设计面板切换 `graphics_mode=overlay` 后：提示词生成提示"不画图形"；生成时自动叠加；
- 段卡显示"已后期叠加/未叠加"状态（取自 take 记录可选）。
