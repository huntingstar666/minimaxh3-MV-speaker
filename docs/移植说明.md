# 移植说明

本工作台刻意做成「一整个目录复制即用」：没有构建步骤、没有前端依赖树、没有数据库、没有外部服务（LLM 与 ASR 都是可选）。下面给出把它搬进其他项目时的完整做法。

## 1. 前置条件

| 项 | 要求 | 说明 |
| --- | --- | --- |
| Python | 3.10+ | 只用标准库 + `fastapi` / `uvicorn` / `httpx` / `numpy` / `python-multipart` / `websockets` |
| ComfyUI | 可访问的 HTTP 服务 | 需要 `selflift-Avatar`、`MiniMaxH3` 系列节点、`VideoHelperSuite` |
| ffmpeg / ffprobe | PATH 或绝对路径 | 归一化、拼接、封面、波形解码 |
| 磁盘 | 每段约 5–20MB | 项目目录会累积 `takes/` |
| 语音识别（可选） | `faster-whisper` | 需 `pip install faster-whisper`；模型从 HF 镜像下载（`HF_ENDPOINT` 可改），GPU 不可用时自动走 CPU int8 |

依赖安装：

```bash
pip install fastapi uvicorn httpx python-multipart numpy websockets
# 可选
pip install faster-whisper
```

## 2. 移植方式

### 方式 A：整目录独立部署（推荐）

```bash
cp -r h3-workbench <目标项目>/apps/h3-workbench
cd <目标项目>/apps/h3-workbench
pip install -r requirements.txt
python run.py
```

适配点：

- 端口：`H3WB_PORT=xxxx python run.py`，或直接 `uvicorn backend.app:app --port 9000`；
- 数据目录：`H3WB_DATA=/srv/h3-data python run.py`（默认落在自身目录的 `data/`）；
- ComfyUI：`COMFYUI_URL=http://gpu-box:8188`；
- ffmpeg：`FFMPEG_PATH=/usr/bin/ffmpeg`。

### 方式 B：挂载到已有 FastAPI / Django / Flask 项目

工作台的路由集中在 `backend/app.py`，只依赖 `backend` 包内的模块，不读取全局状态。可以直接挂载：

```python
# 你的主服务
from fastapi import FastAPI
from backend.app import app as h3_app

main = FastAPI()
main.mount("/h3", h3_app)          # 访问 http://your-host/h3/
```

注意两点：

1. `backend/app.py` 里的 `app.mount("/static", ...)` 是绝对路径。挂载到子路径时，请把 `web/index.html` 里的 `/static/...` 与 `/api/...` 前缀改成相对前缀，或在反向代理层做路径重写。
2. `backend.settings` 使用模块级路径（`ROOT = backend/..`）。若要复用同一个 Python 进程跑多个实例，请通过 `H3WB_DATA` 给每个实例独立数据目录，并在加载前设置。

### 方式 C：只复用编排逻辑（不要 Web UI）

`backend` 里除了 `app.py` 之外都是纯函数/类，可以当作库直接用：

```python
from backend import audio, segmenter, director, prompts, comfy, workflow, media

samples, sr = audio.read_wav("song.wav")
rows, analysis = segmenter.segment(samples, sr, None, "singing", maximum=15, target=11)

project = {"id": "demo", "mode": "singing", "refs": [...], "segments": rows}
director.decorate(project)
manifest = prompts.build_manifest(project["refs"])

# 单段提交
graph = workflow.build(generation, prompt_text, ["h3wb/ref_01.png"], "h3wb/seg.wav",
                       rows[0]["generation_frames"])
prompt_id = comfy.queue(graph)
entry = comfy.wait(prompt_id)
```

`jobs.JobRunner` 也可以直接嵌入：`runner.start(project_id)`，进度通过 `runner.snapshot(project_id)` 读取。

## 3. 必须一起带走的文件

```
backend/        （全部；app.py 可替换成你自己的路由）
web/            （只要静态托管就能跑）
run.py          （可选：仅启动用）
requirements.txt
```

`data/` 不需要带走（运行期生成）。`__pycache__/`、`tmp_test/` 不需要带走。

## 5. 数据与状态

- 每个作品一个目录：`data/projects/<16位id>/`，`project.json` 是唯一真源；
- 原子写：`project.json.tmp → replace`，进程崩溃不会写坏状态；
- 逐段落盘：`takes/seg_0000/clip.mp4` 完成后立即记录 `status=completed`，重启后 `start()` 会跳过已完成段（断点续跑）；
- 迁移到别的机器：整包拷贝 `data/projects/` 即可；媒体路径都是相对项目的；
- 如果目标项目有自己的数据库，建议只把 `project.json` 映射成一张 `h3_projects` 表（字段可直接平铺），媒体仍放对象存储或本地盘。

## 6. 接口契约（前端可替换）

前端 `web/js/api.js` 是唯一的数据访问层。若要把工作台 UI 换成 React / Vue，只需按下列契约对接：

- 所有响应统一 `{ ok: true, ... }`；错误为 HTTP 4xx/5xx + `{ detail }`；
- 项目对象的关键字段：

```jsonc
{
  "id": "…", "name": "…", "mode": "singing|speaking",
  "source": { "duration": 30.1, "sample_rate": 44100 },
  "refs": [ { "filename": "ref_01.png", "role": "performer", "title": "…" } ],
  "segments": [ {
    "index": 0, "start": 0.0, "end": 10.9,
    "start_frame": 0, "end_frame": 262,        // 内部时间的唯一真源（24fps）
    "edit_frames": 262, "generation_frames": 277,
    "camera": "close-up; dolly out…", "brief": "画面任务：…",
    "final_prompt": "…", "prompt_source": "llm|fallback|manual",
    "ref_ids": null,            // null / [] = 继承全局 refs；否则是本段实际用图的下标数组
    "boundary_kind": "auto|manual",
    "status": "idle|running|completed|failed", "output": "takes/seg_0000/clip.mp4"
  } ],
  "manual_boundaries": [10.9],  // 手动切点（秒，仅用于展示）
  "manual_boundaries_frames": [262],  // 手动切点真源（帧）
  "run": { "status": "…", "progress": 0.63, "message": "…", "logs": [ … ] },
  "final": { "path": "final/final.mp4", "thumb": "final/cover.jpg", "duration": 21.6 }
}
```

> 参考图编号规则：`<Picture N>` 永远按**本段实际使用的图片顺序**从 1 开始重排，而不是全局下标。`backend/prompts.py::effective_indices()` 是唯一判定点，前端 `segmentRefIndices()` 与之保持一致。

- 媒体地址：`GET /api/projects/{id}/media/{相对路径}`，支持 `Range`（可直接 `<video src>`）；
- 进度：`GET /api/projects/{id}/run` 轮询，或自行接 ComfyUI `/ws?clientId=…`；
- 生成参数覆盖：`POST /generate` body `{ "generation": { "steps": 6, "seed": 42 }, "only": [0], "force": [0] }`；
- 提示词相关：`project.material_note`（全局创作要求，`@图N` 会转成 `<Picture N>`）、`project.prompt_rule`（额外系统约束）、`segment.note`（本段覆盖）、`segment.brief`（导演简报）、`GET /api/brief-presets`（8 个简报模板）。

## 7. 可替换点

| 想换什么 | 改哪里 | 说明 |
| --- | --- | --- |
| LLM 服务商 | 设置面板 / `data/settings.json` | OpenAI 兼容即可；Ollama、vLLM、DashScope 兼容模式都行 |
| 提示词风格 | `backend/prompts.py`（`SYSTEM_GUARD` + 六段模板） | 改结构后同步改 `validate_prompt()`，否则校验会拦 |
| 运镜池 / 分镜规则 | `backend/director.py::DEFAULT_RULES` | 结构与 `H3-LongVideo/defaults/director_config.json` 一致 |
| 分段策略 | `backend/segmenter.py::segment()` | 候选惩罚、目标时长代价都可调 |
| 采样参数 | 右栏 / `generation` | SelfLift 全参数已暴露 |
| 出片编码 | `backend/media.py` | `crf 18` / `libx264` / `yuv420p` / AAC 192k |
| 存储后端 | `backend/store.py` | 只有 8 个函数（create/save/get/list/delete/read_json/write_json/find_segment） |
| 前端 | `web/` | 零框架，可直接替换 |

## 8. ComfyUI 侧要求

节点可用性在启动时通过 `/object_info` 检测，缺失的可选节点会自动跳过（`workflow.build` 的 `available` 开关）。

最小节点集：

```
UNETLoader CLIPLoader VAELoader LoadImage LoadAudio ResolutionSelector
MiniMaxH3ReferenceToVideo LTXVAudioVAEEncode SolidMask SetLatentNoiseMask
LTXVSeparateAVLatent LTXVConcatAVLatent KSamplerSelect BasicScheduler
ConditioningZeroOut SelfLiftAvatarH3Sampler VAEDecode VHS_VideoCombine
```

若你的 ComfyUI 版本 `object_info` 仍是旧 schema（`[["a","b"], {...}]`），`backend/comfy.py::_unwrap_combo` 已兼容；若未来再变，只改这一个函数。

`SelfLiftAvatarH3Sampler` 的 `vae` 一定接**视频 VAE**；工作流 A 接音频 VAE 的写法不适用。

- [ ] 断点续跑：中断后再 `start()`，已完成段不重复生成

- [ ] 参考图覆盖：`PATCH /segments/{i}` 传 `ref_ids` 后，该段提示词里的 `<Picture N>` 从 1 重排

## 10. 常见坑

1. **上传的素材找不到**：ComfyUI 的 `/upload/image` 会把文件放进 `input/<subfolder>/`，返回 `subfolder/name`。`backend/comfy.py::upload()` 已返回带子目录的路径，`LoadImage` / `LoadAudio` 直接吃这个字符串；自己写代码时不要手工拼 `h3wb/`。
2. **agent 路径**：`store.project_dir()` 会拒绝含 `/ \ .` 的 id，避免路径穿越；从外部传入 id 时保持 16 位 hex。
3. **Windows 编码**：`open(..., encoding="utf-8-sig")` 兼容带 BOM 的 JSON；写文件统一 `utf-8`。
4. **ffmpeg 不在 PATH**：Windows 上 `subprocess` 需要 `CREATE_NO_WINDOW`（已在 `audio.py::_flags()` 处理）。
5. **单卡并发**：`jobs.GPU_LOCK` 是进程级锁，只允许一个项目占用 GPU；要串行化多个实例请用文件锁或队列服务。
6. **音频时长与帧数**：提交前 `slice_wav` 会把本段音频补静音到 `generation_frames/24`，但不会截断成片；拼接时再按 `edit_frames/24` 精确裁齐。
