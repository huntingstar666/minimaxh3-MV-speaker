# 首次安装与环境体检

> 适用：第一次在本机运行 `h3-workbench`，或换了一台 ComfyUI / 显卡环境。
> 目标：用一页把「Python 依赖 → ComfyUI 服务 → ComfyUI 目录 → 节点 → 模型 → 功能可用性」检查清楚，缺什么装什么。

## 0. 一句话

工作台首次启动会自动做一次**只读环境体检**；缺依赖、缺节点、缺模型会列成清单。
节点给仓库地址与一键安装按钮（需确认），模型权重只给目标目录与引导，不自动下载。

## 1. 首次启动会发生什么

1. 服务启动（`start.bat` / `python run.py`）；
2. 浏览器打开 `http://127.0.0.1:8787/`；
3. 前端自动请求 `GET /api/setup/status`，并把结果写进「设置 → 环境体检」；
4. 如果这是**首次使用**（`data/projects` 下还没有项目），或环境有阻塞项，会自动弹出设置面板；
5. 同一浏览器只自动弹一次（`localStorage: h3wb.setupSeen`）。之后点顶部「设置」→「重新检测」随时复查。

> 已有项目的用户不会被打扰；但环境异常时仍会自动弹出，避免带着坏环境去生成。

## 2. 体检项与判定

| 分组 | 检查内容 | 失败影响 |
|---|---|---|
| Python 依赖 | `fastapi` / `uvicorn` / `httpx` / `numpy` / `python-multipart` / `websockets`，可选 `faster-whisper` | 工作台无法启动或缺 ASR |
| 可执行文件 | `ffmpeg` / `ffprobe`（PATH 或设置里的绝对路径） | 无法分析音频 / 拼接成片 |
| ComfyUI 服务 | `GET /system_stats` 连通、版本、显卡 | 无法生成、无法读取节点与模型列表 |
| ComfyUI 目录 | 显式填写 / 环境变量 / 上次缓存 / `system_stats.argv`；必须含 `custom_nodes`、`models` 或 `main.py` | 无法自动部署内置节点、无法扫描磁盘模型 |
| 节点包 | 按 `backend/setup_manifest.json` 检查 `object_info` 里的节点类 | 对应工作流无法提交 |
| 模型 | 合并 ComfyUI 下拉列表 + `ComfyUI/models` 磁盘扫描，按文件名关键词匹配 | 对应功能不可用或只能降级 |
| 功能可用性 | 把节点/模型要求汇总成功能矩阵 | 明确告诉用户「哪个功能不能用、缺什么」 |

状态含义：

- `ready`：节点与模型都齐；
- `blocked`：缺必需项（会列在 `missing`）；
- `unknown`：ComfyUI 未连接，无法判断（先启动 ComfyUI 再检测）；
- `optional`：可选能力（如 LLM 未启用）。

## 3. 节点清单

数据源：`backend/setup_manifest.json`。仓库地址只指向官方/作者仓库，不提供镜像。

| 节点包 | 安装方式 | 仓库 | 目标位置 | 用途 |
|---|---|---|---|---|
| ComfyUI 本体（core） | 升级 ComfyUI | <https://github.com/comfyanonymous/ComfyUI> | ComfyUI 本体 | UNET/CLIP/VAE、H3 Ref2VA、LTXV AV、解码、采样器等 |
| selflift-Avatar | 面板一键 `git clone` | <https://github.com/slmonker/selflift-Avatar> | `custom_nodes/selflift-Avatar` | `SelfLiftAvatarH3Sampler`（MV / 数字人出片必需） |
| ComfyUI-VideoHelperSuite | 面板一键 `git clone` | <https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite> | `custom_nodes/ComfyUI-VideoHelperSuite` | `VHS_VideoCombine` 成片编码 |
| MiniMax H3 Long Video Seam | **项目内置自动部署** | <https://github.com/huntingstar666/minimaxh3-long-video-seam> | `custom_nodes/minimaxh3-long-video-seam` | seam / mixed / 数字人 seam 的逐窗续接 |
| ComfyUI-KJNodes | 可选 | <https://github.com/kijai/ComfyUI-KJNodes> | `custom_nodes/ComfyUI-KJNodes` | 预览/缩放参考工作流 |
| ComfyUI-Easy-Use | 可选 | <https://github.com/yolain/ComfyUI-Easy-Use> | `custom_nodes/ComfyUI-Easy-Use` | 显存清理模板 |

说明：

- 内置 seam 节点由 `backend/seam_nodes.py` 从项目 `vendor/minimaxh3-long-video-seam/` 复制，启动时自动尝试一次；面板也可手动「部署」。**只复制文件，不重启 ComfyUI**。
- 上游 `git` 节点安装后，如果仓库带 `requirements.txt`，面板会给出用 ComfyUI 自己的 Python 执行的命令；不会把依赖装进系统 Python。
- 节点安装/部署完成后必须**手动重启 ComfyUI**，否则 `object_info` 里仍然看不到新节点。
- 不要在 `custom_nodes` 里同时保留两个同名 TimelineDirector，否则会重复注册节点。

## 4. 模型清单

模型权重不随仓库分发，也不自动下载。工作台只检查「有没有匹配文件」并引导放置。

| 模型 | 目标目录 | 文件名关键词 | 必需 | 影响 |
|---|---|---|---|---|
| H3 UNET | `ComfyUI/models/diffusion_models`（或 `models/unet`） | `minimax_h3_fl2va` / `minimax_h3_ref2va` / `h3_hybrid` / `cobijada` / `w4a8` | 是 | 全部出片 |
| H3 文本编码器 | `ComfyUI/models/text_encoders`（或 `models/clip`） | `qwen3vl_32b_minimax_h3` | 是 | 全部出片 |
| H3 视频 VAE | `ComfyUI/models/vae` | `minimax_h3_video_vae` | 是 | 全部出片 |
| H3 音频 VAE | `ComfyUI/models/vae` | `minimax_h3_audio_vae` | 是 | 全部出片 |
| 潜空间放大器 | `ComfyUI/models/latent_upscale_models`（或 `models/upscale_models`） | `minimax_h3_latent_upscaler` | 是 | SelfLift 二采 / 数字人双采 |
| 加速 / 人物 LoRA | `ComfyUI/models/loras` | `dmad` / `h3_character_swap` / `fl2v_turbo` / `minimax_h3_lora` | 否 | 速度、人物一致性 |

放置后二选一：

1. 回到「设置 → 模型」下拉里选择实际文件名；
2. 保持留空，让后端按关键词自动匹配（`backend/avatar/workflow.py`、`backend/jobs.py`）。

> 模型许可以发布者为准（MiniMax H3 Community License、LoRA 作者条款等）。工作台不判断地区适用性，也不替用户接受许可。

## 5. 安装动作与安全边界

| 动作 | 入口 | 行为 |
|---|---|---|
| 安装 Python 依赖 | 设置 → 环境体检 →「安装必需依赖」 | 用当前工作台 Python 执行 `pip install --upgrade` manifest 白名单包；900 秒超时 |
| 安装语音识别依赖 | 「安装语音识别依赖」 | 只安装 `faster-whisper`（可选） |
| 安装上游节点 | 节点行的「git 安装」 | `git clone --depth 1 <repo> <ComfyUI>/custom_nodes/<name>`；目标已存在则拒绝，不覆盖用户目录 |
| 部署内置 seam 节点 | 节点行自动出现 / 面板按钮 | 复制 `vendor/minimaxh3-long-video-seam`，旧目录备份为 `.disabled` |
| 填 ComfyUI 目录 | 「ComfyUI 根目录」→ 保存并检测 | 校验 `custom_nodes`/`models`/`main.py` 后写入 `data/comfy_dir.txt` |
| 模型 | 无自动下载 | 只列清单、目录与关键词；用户在设置里选或自行下载 |

所有安装动作都必须先在前端确认；后端也要求 `confirm=true`。
不会自动重启 ComfyUI、不会自动提交生成任务、不会从非官方来源抓取权重。

## 7. API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/setup/status?scan=true` | 完整体检（15 秒缓存；`scan=false` 用最近结果） |
| POST | `/api/setup/comfy-dir` | `{path}` 保存并检测 ComfyUI 根目录 |
| POST | `/api/setup/install/python` | `{confirm:true, optional:false}` 安装白名单依赖 |
| POST | `/api/setup/install/nodes` | `{id, confirm:true, root?, force?}` 安装/部署节点包 |

返回里的 `blockers`、`nodes.missing`、`models.missing`、`features[].state` 可直接用于 UI 或自动化。

## 8. 手动安装（不点按钮时）

```powershell
$COMFY = "D:\ComfyUI"
$NODES = Join-Path $COMFY "custom_nodes"

# 上游节点
git clone --depth 1 https://github.com/slmonker/selflift-Avatar.git       (Join-Path $NODES "selflift-Avatar")
git clone --depth 1 https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite.git (Join-Path $NODES "ComfyUI-VideoHelperSuite")

# 内置 seam 节点（也可以让工作台自动部署）
Copy-Item -Recurse -Force .\vendor\minimaxh3-long-video-seam (Join-Path $NODES "minimaxh3-long-video-seam")

# 节点自带依赖：必须用 ComfyUI 的 Python，不要用系统 Python
& "$COMFY\python_embeded\python.exe" -m pip install -r (Join-Path $NODES "ComfyUI-VideoHelperSuite\requirements.txt")
```

重启 ComfyUI 后回到工作台点「重新检测」，节点列表应变为「已装」。

## 9. 排错

| 现象 | 优先检查 |
|---|---|
| 体检显示「ComfyUI 未连接」 | ComfyUI 是否启动；地址是否 `http://127.0.0.1:8188`；代理/端口 |
| 显示「ComfyUI 目录未定位」 | 在设置里填根目录（含 `custom_nodes`/`models`）；或设 `COMFYUI_DIR` |
| 节点显示缺失但 ComfyUI 里能看到 | 是否重启过 ComfyUI；是否装到了另一个 ComfyUI；是否重复目录 |
| seam 节点「已部署但未加载」 | 重启 ComfyUI；看启动日志有没有 import 报错；ComfyUI 是否 0.43+ |
| 模型显示缺失但文件存在 | 检查文件名关键词；确认放在 `ComfyUI/models/...` 而不是项目目录 |
| 依赖安装失败 | 看面板返回的 pip 输出；确认当前工作台 Python 可写；必要时手动 `pip install -r requirements.txt` |
| `git` 安装按钮不可用 | 未安装 Git 或不在 PATH；按上面的手动命令安装 |

## 10. 维护约定（给下一位开发者）

- **唯一数据源**：节点、模型、功能依赖只改 `backend/setup_manifest.json`；不要在前端或 `setup_check.py` 里另写一份名单。
- 新增节点/模型时同步更新：
  1. `backend/setup_manifest.json`（节点类名、仓库、目标目录、模型关键词）；
  2. 本文件第 3/4/6 节；
  3. `README.md` 的「环境要求」与「API 一览」；
  4. 相关测试（`setup_check_test.py`；新增功能时加对应 feature）。
- 节点/模型安装方式变化（例如改为 ComfyUI Manager 包）时，改 manifest 的 `install` 与 `destination`，不要改 UI 逻辑。
- 过期描述优先删除或改写，不要在文档里保留「曾经如何」的长段落；历史决策放 `docs/BUG审查-20261111.md` 或提交记录。
- 文档入口统一放在 `README.md` §0.7 / §2；新增文档必须从 README 链到，避免孤岛。
