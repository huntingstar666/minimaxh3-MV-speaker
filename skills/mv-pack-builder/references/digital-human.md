# 数字人 / 口播包专项说明

数字人项目与 MV 共用 `.h3pack.zip` 格式，区别只有 `"mode": "speaking"`。工作台会：

- 导演固定机位、中近景，全片构图一致；
- 按口播音频驱动口型（`performance`）；
- 长音频按气口/句界切段，段间硬切但构图保持一致。

## 1. 需要用户提供的素材

| 素材 | 要求 |
| --- | --- |
| 人物参考图 | 1 张，正面/半身，五官清晰，光线均匀；避免遮挡、滤镜、多人合照 |
| 音频 | 口播人声，16kHz 以上，尽量去噪；单人；时长不限（长音频会分段） |
| 口播稿 | 与音频逐句对应；用于切分、口型节奏与提示词；没有则依赖音频分析 |
| 场景图（可选） | 房间/纯色背景/虚拟背景；画面内文字会被要求不可读 |
| 服装造型（可选） | 需要固定服装细节时提供 |
| 风格/滤镜（可选） | 如“明亮办公”“柔和胶片”；不要与写实口播冲突 |
| 参数 | 模式 speaking、目标/最长段长（推荐 8/12；一般单段 ≤15s，特殊可到 30s，需确认）、画幅、帧率、硬切或 seam |
| 多角色（可选） | 默认不支持多人同框分别对口型；建议按说话人拆音频/分段 |

## 2. 推荐参数

```json
{
  "mode": "speaking",
  "project": {
    "target_seconds": 8,
    "max_seconds": 12,
    "script": "口播稿全文……",
    "generation": {
      "output_fps": 24,
      "aspect_ratio": "9:16 (Portrait Widescreen)",
      "stitch": "hard"
    }
  }
}
```

- 画幅按发布平台选：竖屏 9:16、横屏 16:9、方屏 1:1。
- 口播多为固定机位，`stitch: "seam"` 只适合相邻段完全同机位/同构图；否则用 hard。
- 单段一般 ≤15 秒（H3 推荐区间）；特殊长句可到 30 秒，但要在设计审阅时和用户确认。
  长口播由工作台自动切分，先出一段给用户确认，再批量生成。

## 3. 提示词 / 简报模板

### performance（会说话、对口型）

```text
画面任务：人物口播
声音关系：人物跟随本段人声做自然可见口型，停顿和呼吸与音频一致
开场构图：沿用参考画面的原有构图，保持人物位置、人物尺度、身体可见范围、头顶留白和裁切边界
主体动作：自然口播，保留眨眼、呼吸和克制的小幅头部、肩部与手势动作
镜头运动：全程固定机位单一连续镜头，背景透视和构图跨段保持一致
结束构图：保持与开场一致的人物尺度、位置、裁切边界和背景透视
```

### atmosphere（闭口氛围，不要求口型）

```text
画面任务：人物氛围表演
声音关系：人物不说话、不做口型，只以视线、呼吸和克制动作回应本段声音
开场构图：中近景正面，人物位置与参考图一致
主体动作：人物保持闭口，以自然眨眼、呼吸、视线和小幅身体动作维持画面生命感
镜头运动：全程固定机位单一连续镜头
结束构图：保持与开场一致
```

### environment（纯背景空镜/转场）

```text
画面任务：空镜环境
声音关系：不出现人物，不要求口型同步；原曲由最终工作流恢复
开场构图：沿参考场景既有构图开场，保持空间结构、地标、材质、灯光和透视关系
主体动作：仅呈现指定环境及其原有可见元素，不新增人物、字幕、歌词文字或图形覆盖
镜头运动：固定机位或轻微推进，保持参考场景身份稳定
结束构图：结束在可自然承接下一分段的空间构图
```

## 4. final_prompt 自检

- 六段结构齐全且顺序正确；
- `performance` 在 `subject_definitions` 声明 `<Audio 1>`，并写自然口型/停顿/呼吸；
- `atmosphere` 不声明 `<Audio 1>`，明确闭口；
- `environment` 不出现人物；
- 固定机位/构图一致（除非用户明确要求运镜）；
- 两个声音段都是 `N/A`；结尾包含无字幕水印声明；
- 不写“读出屏幕上文字”“字幕”等要求。

完整六段结构见 [prompt-rules.md](prompt-rules.md)。

## 5. 工作流建议

1. 环境自检通过 → 打素材包（`mode: speaking`）。
2. 导入工作台后先核对：分段数、段长、人物参考图角色、第一段提示词。
3. 先「开始生成」只生成第 1 段（工作台支持单段重生成；全量生成前确认形象/口型）。
4. 确认后批量生成 → 拼接 → 成片下载；需要换条时用段卡右侧选片台。
5. 交付包 + 成片；包可再导入复现。

## 6. 什么情况不要用数字人口播模式

- 多人对话且要求每个人分别对口型 → 拆成多个项目/音频分别生成；
- 需要复杂运镜/换景/舞台表演 → 用 MV（singing）模式；
- 需要把字幕烧进画面 → 工作台不烧字幕，成片后用剪辑软件加。
